An entry for the [make.fun bounty "The poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235) ($50 USDC).

`main.py` writes one short original poem about agency — the power to ask
and to be given, and the power handed back — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`. To write elsewhere, set
`MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/poem-out python3 main.py
```

No network, Python standard library only.
